# GRIP-The-Spark-Foundation

This repository contains the tasks completed as part of the Data Science & Business Analytics internship by The Spark Foundation (GRIP).

## Project Overview

The project includes two machine learning notebooks and one Power BI file:

- `GRIP1.ipynb` — Prediction using Supervised ML
- `GRIP2.ipynb` — Prediction using Unsupervised ML
- `Retail GRIP.pbix` — Business analytics dashboard file

## Tasks Included

### 1. Prediction using Supervised ML

In this task, we build a simple linear regression model to predict a student's percentage based on the number of study hours.

Key points:

- Dataset: Student study hours vs scores
- Model: Linear Regression
- Objective: Predict score for a student studying 9.25 hours/day
- Result: The notebook predicts a score of approximately 92.91%

### 2. Prediction using Unsupervised ML

This task uses the Iris dataset to determine the optimal number of clusters using the K-Means algorithm.

Key points:

- Dataset: Iris flower dataset
- Technique: K-Means Clustering
- Method: Elbow method to find optimal cluster count
- Result: Optimal number of clusters is 3

## Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/your-username/GRIP-The-Spark-Foundation.git
```

2. Open the notebooks in Jupyter Notebook or JupyterLab.

3. Install the required dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn openpyxl
```

4. Run each notebook cell in order to reproduce the analysis.
